# Capítulo 3: Software y Comunicaciones

Este bloque describe la lógica de programación del microcontrolador, los protocolos de transmisión de datos hacia el servidor central y la estructura de la base de datos de usuarios.

## 3.1 Arquitectura del Firmware (RTOS)
> El firmware del sistema de control de acceso se ejecuta sobre un microcontrolador ESP32 utilizando el sistema operativo en tiempo real **FreeRTOS**. El uso de un RTOS permite dividir el programa en tareas independientes que se ejecutan de forma concurrente, garantizando que las operaciones críticas (como la apertura de la cerradura) respondan en un tiempo acotado aunque el sistema esté ocupado con otras funciones, como la comunicación con el servidor.
